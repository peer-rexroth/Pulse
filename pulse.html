Choose your role

This is a workflow setting, not a security boundary — Pulse has no accounts or server, so it only guides what's shown/enabled in the UI. The role you pick is saved to this browser only, never written to a shared/synced data file — but Reviewer/Editor/Admin can each optionally require a password (set by an Admin, under Settings > Role Passwords) to cut down on accidental switches. Only a salted hash of that password is stored in the shared data file, not the password itself — but the check still runs in this page's own code, so it's a soft deterrent, not real access control.

Role Passwords

Required to switch into that role from the role picker. Only a salted hash is stored, never the password itself, so these fields always start blank — type a new password to set or change one, and leave it blank to leave that role unchanged.

Admin's password requirement can't be removed once set — only changed to a different password.

How Pulse works

Overview
Pulse is a local-first programme dashboard, organized into Planning, Review, Dashboard, and Settings. Everything runs in your browser — no account, no server.
Planning
Organize work into workstreams, each holding scope items with a milestone checklist. Picking a category seeds that checklist from a reusable template (Settings → Scope Item Categories).
Drag items (or whole workstreams, in the sidebar) to reorder them. A quick-added item lands in Unassigned for later triage — mark its one milestone Complete to assign it a real workstream and category.
Use the search box and the status/Dependencies pills above the board to narrow a long list down to what you're looking for.
Review
Start a review cycle for one workstream at a time and confirm each item/milestone as you go — one already marked Complete confirms itself. A cycle can only close once everything in it is confirmed.
Attach meeting minutes to a completed cycle — paste or drop a document and it auto-fills Summary, Decisions, Next Steps, and a real Action Items table.
Action items and decisions feed an Action Log/Decision Log that spans every review cycle for a workstream, not just the one they came from. A Change Log tab shows every edit logged across every workstream's reviews in one place.
Dashboard
A read-only rollup — RAG status, milestone completion, and workstreams overdue for review — plus Overdue/Upcoming feeds of what needs attention next.
Download it as a one-page Exec Summary (PDF or PNG) from the toolbar, ready to drop into a status deck.
Roles
A soft role ladder — Visitor → Reviewer → Editor → Admin — meant to guide day-to-day workflow on a shared device, not real access control. Switch roles any time from the shield icon; an Admin can optionally require a password per role.
Data & sync
Your data is stored locally in this browser. It persists between sessions on this device but isn't synced anywhere by default.
Link file (Chrome/Edge) auto-saves every change to a real .json file on disk — shareable via something like OneDrive/SharePoint — and merges in changes made elsewhere.
Export downloads a one-off backup; Import loads one back in, merging or replacing your current data. Export to Excel produces a formatted report instead.
Nothing here ever leaves your machine unless you link a file yourself — there's no server, no account, and no admin rights required to run this app. Automatic daily snapshots (last 7 days) are also available under Data → Backups.
